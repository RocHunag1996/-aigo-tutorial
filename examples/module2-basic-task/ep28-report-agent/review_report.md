# 锂电池正极材料低温性能研究进展

## 1. 引言

锂电池因其高能量密度和长循环寿命而被广泛应用于便携电子设备、电动汽车及储能系统。然而，在低温环境下（如-20°C以下），电池的容量急剧衰减、功率输出下降，严重制约了其在寒冷地区的实际应用。正极材料作为决定锂离子电池电化学性能的关键部件，其低温性能劣化尤为突出：离子扩散系数降低、电荷转移阻抗增大，导致倍率性能恶化。当前主流正极材料如LiCoO₂、LiNiₓCoᵧMn₁₋ₓ₋ᵧO₂（NCM）及LiFePO₄（LFP）在低温下均表现出不同程度的活性物质利用率下降与极化加剧。为突破这一瓶颈，研究者通过体相掺杂、表面包覆、纳米化及电解质界面调控等策略，致力于提升正极材料的低温离子传导与结构稳定性。本文旨在综述近年来锂电池正极材料低温性能改进方面的研究进展，分析不同改性策略的作用机制与局限性，并展望未来发展方向，为高性能宽温域锂离子电池的设计提供参考。

## 2. 研究现状与方法对比

针对LFP低温性能提升，三种方法呈现明显差异。Paper A采用常规电解液，在-10°C下容量仅95 mAh/g，表明传统体系低温动力学严重受限。Paper B通过引入醚类电解质，在-20°C下实现140 mAh/g，性能大幅超越前者，归因于醚类溶剂低凝固点和高离子电导率，但醚类电解质的氧化稳定性较差，可能限制高压兼容性及长循环寿命。Paper C则从机理层面指出，低温瓶颈主要来自界面电荷转移而非体相离子扩散，这意味着单纯提高电解质电导率（如B法）可能无法充分解锁容量，需同时优化电极/电解质界面（如构建薄且稳定的SEI膜）。综合而言，B法更适合对低温容量要求极致的应用场景（如极寒地区动力电池），但需权衡耐久性；A法适用于常规低温工况；而C法为后续开发提供了精准方向，即界面工程策略应作为核心突破点。

## 3. Research Gap 分析

在材料科学研究中，上述三个研究空白分别对应数据缺失、结论矛盾与方法迁移滞后，其成因、影响与价值各有不同。LiFePO₄在-30°C以下的电化学性能数据缺失，主要源于传统低温实验设备多限于-20°C，且极低温工况在早期应用（如储能电站）中关注不足，导致关键性能窗口空白。该数据缺失直接制约了电动汽车在寒区及航空极寒场景下的电池选型与安全评估，填补此空白可揭示极低温下锂离子扩散与相变机制，为低温电解液设计提供依据。LLZO晶界阻抗贡献的矛盾（10% vs 70%）则归因于样品烧结工艺差异（如杂质相、致密度）、两探针与四探针阻抗谱解析方法的不统一，以及等效电路模型选择的主观性。这一分歧使固态电解质性能优化缺乏共识性瓶颈识别，削弱了材料设计的针对性。系统性对照实验与标准化测试协议的研究价值在于厘清晶界主导失效模式，推动高离子电导LLZO的工程化。机器学习方法未迁移至热电材料载流子优化，根源于热电领域缺乏高通量生成的电输运数据集，且特征参数（如能带简并度、散射机制）的物理对应性较弱，难以直接套用催化剂的活性位点预测框架。然而，催化剂领域的成功已证明ML在高维特征空间中的映射能力，因此将迁移学习、图神经网络引入热电载流子浓度与迁移率协同优化，有望突破传统试错法的效率瓶颈，加速新型热电材料的理性设计。综上，三个空白分别指向数据拓展、争议消解与方法创新，均具有推动领域范式升级的重要价值。

## 4. 未来展望与建议

针对上述研究空白，未来可从三方面切入：首先，应系统构建LiFePO₄在-30°C至-60°C的低温电化学性能数据库，结合原位XRD与阻抗谱解析相变动力学与电荷转移限制；其次，采用聚焦离子束-扫描电镜联合阻抗谱及相场模拟，定量解耦LLZO晶界与晶粒的离子输运贡献，明确烧结工艺对晶界成分与空间电荷层的影响；最后，亟需将图神经网络与主动学习迁移至热电领域，建立“组成-能带结构-载流子输运”的端到端预测模型，并利用贝叶斯优化自主筛选p/n型掺杂剂与最佳载流子浓度。这些方向有望填补低温储能机制、固态电解质界面调控及热电材料高通量设计的空白，推动相关领域从经验试错向数据驱动范式转变。
