## 从 0 开始构建材料科学文献驱动的科学发现智能体 · 教程总目录

**系列名称**：从 0 开始构建材料科学文献驱动的科学发现智能体
**公众号**：小黄的材料AI Lab
**目标读者**：材料领域研究生
**风格**：概念讲解 + 可运行代码，每篇 2500–4000 字
**总期数**：64 期，分五大模块

> 目标：带你从零搭建一个能自主检索文献、解析 PDF、抽取知识、识别 Research Gap、生成调研报告的科学发现智能体，再进一步扩展到构效关系发现、模拟方法、合成路线三个方向。

### 模块一：LLM 与 Agent 基础认知（第 01–08 期）

> 不造轮子，先理解轮子。让读者知道 LLM 能做什么、不能做什么，Agent 到底是个什么东西。

| 期数 | 标题（草案） | 核心内容 |
|---|---|---|
| 01 | 大语言模型 101：GPT/Claude/DeepSeek 到底在干嘛 | Transformer 直觉解释、token、上下文窗口、temperature——不需要推公式，但要理解边界 |
| 02 | Prompt Engineering：跟 LLM 说话的学问 | 系统提示词、Few-shot、CoT、输出格式控制——用 DeepSeek API 实操 |
| 03 | 调用大模型 API：从 curl 到 Python | OpenAI 兼容接口、流式输出、错误重试、token 计费——写一个可复用的 llm_call.py |
| 04 | Function Calling：让 LLM 学会"动手" | 工具描述 schema、模型选择工具、参数提取——这是 Agent 的核心机制 |
| 05 | Agent 到底是什么？不是魔法，是循环 | Observe→Think→Act 循环、ReAct 模式、Agent 与普通 chatbot 的区别 |
| 06 | 动手搭你的第一个 Agent（纯 Python，50 行） | 用 DeepSeek + Function Calling 写一个能查天气+算材料的 mini Agent |
| 07 | Agent 框架选型：LangChain / CrewAI / 手写 | 各框架优劣对比、什么时候该用框架、什么时候手写更干净 |
| 08 | 模块一总结：Agent 的能力边界与常见坑 | 幻觉、上下文溢出、工具调用失败的处理策略 |

### 发布节奏建议

- **第 1–30 期（核心任务）**：每周 2–3 篇，约 3–4 个月完成。这是整个系列的主干，把文献调研智能体从零搭起来。
- **第 31–64 期（三个进阶方向）**：每周 1–2 篇，按方向交替发布（A→B→C→A→…），保持各方向读者的关注度。

### 每篇固定结构

1. **开头**：大家好，我是小黄。（+ 本期引入，1–2 句）
2. **正文**：概念讲解 → 代码实操 → 结果分析，每 300–500 字一个小标题
3. **配图**：流程图/代码截图/运行结果截图，3–5 张
4. **结尾**：感谢 + 求互动 + 下期预告
5. **代码仓库**：每篇对应的完整代码在 GitHub 仓库可获取（部分纯概念篇无代码）
